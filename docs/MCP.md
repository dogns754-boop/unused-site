# MCP 도구 — 모든 프로젝트가 함께 쓰는 "상위" 도구

**MCP** 는 Claude 에게 끼워 주는 *추가 도구*입니다. 예를 들어 "최신 라이브러리 설명서 찾아보기" 같은 능력을 더해 줍니다.
이 저장소 맨 위의 `.mcp.json` 에 적힌 도구는 **모든 프로젝트에서 자동으로** 쓸 수 있습니다.

## 지금 켜져 있는 것

| 도구 | 하는 일 | 왜 필요한가 |
|---|---|---|
| **Context7** | 라이브러리의 **최신 공식 설명서**를 찾아 읽음 | AI 가 옛날 방식으로 코드를 쓰는 실수를 줄임 (WPF, Expo 처럼 자주 바뀌는 것) |
| **REA** | 프로그램이 어떻게 동작하는지 분석 (아래 설명) | 참고 프로그램·내 프로그램 분석 |

> 처음 쓸 때 Claude Code 가 "이 MCP 서버를 허용할까요?" 라고 물으면 허용하세요.
> 클라우드 세션은 네트워크 정책 때문에 Context7 에 연결되지 않을 수 있습니다 — 내 PC 의 Claude Code 에서는 동작합니다.

## 따로 설치하지 않아도 이미 있는 것

| 기능 | 어디서 | 쓰임 |
|---|---|---|
| GitHub 검색·읽기·PR | claude.ai 에 GitHub 연결 시 | `/research` 에서 오픈소스 찾기 |
| 웹 검색 | Claude Code 기본 기능 | 오류 메시지·사용법 찾기 |
| 컴퓨터 화면 보기·조작 | Claude 데스크톱 앱의 *computer use* | 내 PC 에서 만든 프로그램을 Claude 가 직접 띄워 보고 확인 |

## 필요해지면 추가할 것 (선택)

| 도구 | 언제 | 추가 방법 (내 PC 터미널) |
|---|---|---|
| Playwright | `web` 유형 프로젝트를 브라우저로 자동 테스트할 때 | `claude mcp add playwright -- npx @playwright/mcp@latest` |

추가한 뒤 모든 프로젝트에서 같이 쓰고 싶으면 `--scope project` 를 붙이면 `.mcp.json` 에 저장됩니다.

## REA — 리버스 엔지니어링 도구 (`.mcp.json` 의 `rea`)

[REA (Reverse Engineer Anything)](https://github.com/morluto/rea) — MIT 라이선스, 버전 6.5.0 고정 (`tools/package.json`).
소스 코드 없이 프로그램이 **어떻게 동작하는지** 들여다보는 도구입니다. 결과마다 근거(어느 코드·어느 호출)를 같이 보여줍니다.

### 할 수 있는 것

| 대상 | 무엇을 알려주나 | 필요한 것 |
|---|---|---|
| .NET 프로그램 (C# — 우리 프로그램도 여기) | 클래스·메서드·사용하는 Windows 기능 | 없음 |
| JavaScript / Electron 앱 | 모듈 구조, 기능 흐름 | 없음 |
| 일반 Windows exe (C++ 등) | 함수, 문자열, 호출 관계 | Ghidra 등 분석기 설치 (Windows 지원은 실험 단계) |
| 실행 중인 프로그램의 화면 | 창·버튼 구성, 어떤 동작이 어떤 기능을 부르는지 | 내 PC 에서 실행 |

### 이 워크스페이스에서 쓰는 규칙

| 대상 | 사용 | 이유 |
|---|---|---|
| **우리가 만든 프로그램** (exe 용량, 느린 부분, 버그 추적) | ✅ 자유롭게 | 내 것 |
| **오픈소스 프로그램** (ShareX 등) | ✅ | 라이선스가 허용. 단 GPL 코드 복사는 사용자 확인 |
| **상용 프로그램의 화면·동작 관찰** (픽픽의 창 구성, 메뉴 항목, 단축키 흐름) | ✅ | 프로그램을 써 보며 보는 것과 같은 수준 |
| **상용 프로그램 디컴파일 → 코드·리소스 복사** | ❌ | 대부분의 사용 약관 위반 + 저작권 문제. REA 자체도 이 용도를 지원하지 않는다고 밝힘 |

> 원하는 기능 대부분은 오픈소스(ShareX 등)에 구현 방법이 이미 공개되어 있어, 상용 프로그램 내부를 뜯을 필요가 거의 없습니다.

### 설치

- 클라우드 세션: 세션 시작 때 자동 (`scripts/setup.sh`)
- 내 PC: `scripts/setup-windows.ps1` 이 설치. 직접 하려면 저장소 폴더에서 `cd tools && npm install`
- 처음 쓸 때 Claude Code 가 "MCP 서버 rea 를 허용할까요?" 라고 물으면 허용
- 일반 exe 를 깊게 분석하려면 Ghidra 가 따로 필요합니다 — 필요해지면 Claude 가 안내합니다.
