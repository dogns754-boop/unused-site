# 버그 수정

대상: `$ARGUMENTS`

1. **재현**: 증상을 그대로 일으키는 테스트를 쓰고 `scripts/check.sh <프로젝트>` 로 실패를 확인한다.
   재현이 안 되면 추측으로 고치지 말고, 재현에 필요한 정보(입력값, 에러 메시지, 환경)를 사용자에게 묻는다.
2. **원인**: 증상이 아니라 원인을 찾는다. 원인을 한두 문장으로 설명할 수 있어야 한다.
3. **수정**: 원인을 고치는 최소한의 변경. 같은 원인으로 생길 다른 버그가 보이면 함께 테스트한다.
4. **검증**: `scripts/check.sh <프로젝트>` 전체 통과.
5. **기록**: CHANGELOG.md `[Unreleased]` → `### 수정` 에 한 줄.
6. **커밋**: `[<프로젝트>] fix: <요약>`
7. **보고**: 원인 / 수정 내용 / 추가한 테스트를 짧게.
