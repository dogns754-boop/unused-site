# 세션 마무리

대상: `$ARGUMENTS` (없으면 `git status` / 최근 커밋으로 오늘 손댄 프로젝트를 찾는다)

1. **검사**: 바뀐 프로젝트마다 `scripts/check.sh <프로젝트>`. 실패하면 먼저 고친다.
2. **자체 리뷰**: 이번 세션의 diff(`git diff` 와 오늘 커밋들)를 다시 읽고 확인한다.
   - 디버그 출력, 주석 처리된 코드, 하드코딩된 경로·비밀값이 남지 않았는가
   - 테스트 없이 들어간 로직이 없는가
   - 고칠 게 있으면 고치고, 변경이 크면 `/code-review` 를 권한다.
3. **문서**:
   - PLAN.md 체크박스·상태, PROJECTS.md 상태가 실제와 맞는가
   - PLAN.md `작업 기록` 에 오늘 날짜로 한 일 / 다음에 할 일 1~2줄
   - README 실행 방법이 최신인가
4. **커밋**: 남은 변경을 규칙대로 커밋한다 (`[<프로젝트>] docs: 작업 기록 정리` 등).
5. **푸시**: 현재 브랜치를 `git push -u origin <현재 브랜치>` 로 푸시한다.
6. **요약**: 오늘 한 일, 현재 진행률(`scripts/status.sh`), 다음 세션에서 시작할 명령 (예: `/feature todo-cli`).
