# 참고 프로그램 분석

대상: `$ARGUMENTS`

목표는 **남의 프로그램을 베끼는 것이 아니라**, 잘 만든 오픈소스에서 *어떻게 구현했는지*를 배워 내 프로그램에 빠르게 적용하는 것이다.

## 1. 찾기
- `projects/<프로젝트>/PLAN.md` 의 핵심 기능을 읽는다.
- 사용자가 프로그램을 지정했으면 그것부터. 아니면 GitHub 에서 비슷한 **오픈소스** 2~4개를 찾는다
  (별 수, 최근 업데이트, 같은 언어/플랫폼 우선 — windows 유형이면 C#/WPF 우선).
- 상용 프로그램(예: 픽픽, 알PDF)은 소스가 없으므로 **기능 목록과 화면 흐름만** 참고 대상으로 적는다.
  사용자 PC 에서 실행 중이면 REA MCP 의 화면 관찰 도구로 창·메뉴 구성을 정리할 수 있다.
  상용 프로그램을 디컴파일해 코드를 읽거나 복사하지 않는다 (약관·저작권 위반 소지).
- 오픈소스 프로그램의 **빌드된 exe 만 있고 소스 위치를 찾기 어려울 때**는 REA 로 구조를 먼저 훑고 소스에서 해당 부분을 찾는다.

## 2. 내려받기
- `git clone --depth 1 <주소> references/<프로젝트>/<저장소이름>` (references/ 는 git 에 올라가지 않음)
- 저장소 루트의 `LICENSE` 를 먼저 확인한다.

## 3. 분석 — 내 PLAN.md 의 기능별로
- 그 기능을 구현한 파일·클래스 위치
- 사용한 Windows API / 라이브러리 (예: 화면 캡처 API, OCR, GIF 인코더)
- 그대로 쓸 만한 아이디어, 피해야 할 점 (복잡도, 오래된 API)
- 큰 저장소는 전부 읽지 말고 기능 이름으로 검색해 해당 부분만 읽는다.

## 4. 기록
`projects/<프로젝트>/REFERENCES.md` 의 표와 `분석 메모` 를 채운다. 기능마다:
> **범위 캡처** — ShareX `ShareX.ScreenCaptureLib/RegionCaptureForm.cs` 참고. 오버레이 창 + 마우스 훅 방식. 우리 Core 의 `RegionMath` 로 좌표 계산만 분리하면 테스트 가능.

## 5. 라이선스 규칙 (중요)
| 라이선스 | 코드 복사 | 비고 |
|---|---|---|
| MIT, BSD, Apache-2.0 | ✅ | 파일 상단에 출처·라이선스 주석을 남긴다 |
| GPL, LGPL, AGPL | ⚠️ | 복사하면 이 프로젝트도 같은 라이선스여야 한다. 사용자에게 먼저 묻는다. 구조·방식만 참고하는 것은 괜찮다 |
| 라이선스 없음 / 상용 | ❌ | 코드 복사 금지. 동작·화면만 참고 |

코드를 실제로 가져왔다면 PLAN.md `기술 결정` 에 출처와 라이선스를 적는다.

## 6. 마무리
