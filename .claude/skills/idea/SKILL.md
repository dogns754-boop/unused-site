# 아이디어 정리

입력: `$ARGUMENTS`

1. `IDEAS.md` 와 `PROJECTS.md` 를 읽는다.
2. **기존 프로젝트에 대한 기능 아이디어**면 → 해당 `projects/<이름>/PLAN.md` 의 `나중에` 에 추가하고 끝낸다.
   (MVP 에 넣어야 할 만큼 중요하다고 사용자가 말하면 `핵심 기능` 맨 아래에 체크박스로 추가)
3. **새 프로그램 아이디어**면 → `IDEAS.md` 의 `## 아이디어 목록` 마지막 항목 뒤(`---` 위)에 아래 형식으로 추가한다.
   사용자의 말을 최대한 살리되, 기능을 번호 목록으로 정리한다. 모르는 건 지어내지 말고 `열린 질문`에 적는다.

   ```markdown
   ### 보다 간단한 <무엇> — `<영문-이름>` (제안)
   - 날짜: YYYY-MM-DD
   - 플랫폼: windows / mobile / web / python …  (추천 이유 한 줄)
   - 한 줄 요약:
   - 참고 프로그램:
   - 주요 기능:
     1. …
   - 열린 질문:
   ```
4. 사용자가 길게 쓴 원문은 IDEAS.md `원문 기록` 에 `<details>` 로 그대로 보존한다 (나중에 의도를 다시 확인할 수 있게).
5. 사용자에게 정리한 내용을 보여주고, 바로 시작할지 묻는다 → 시작하면 `/new-project` 흐름으로.
6. 커밋: `[workspace] docs: 아이디어 추가 — <제목>`
