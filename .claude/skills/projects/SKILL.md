# 프로젝트 현황

1. `scripts/status.sh` 를 실행하고 PROJECTS.md 를 읽는다.
2. 표로 정리한다: 프로젝트 / 상태 / 진행률 / 최근 커밋 / 다음 할 일.
3. PLAN.md 와 PROJECTS.md 의 상태가 다르면 알려준다 (고칠지 물어본다).
4. 추천 1~2개: 거의 끝난 프로젝트 마무리를 우선하고, 오래 멈춘 프로젝트는 `💤 보류` 로 바꿀지 제안한다.
