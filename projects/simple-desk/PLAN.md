# simple-desk 기획서 — 보다 간단한 바탕화면

> PC방의 바로가기 정리 프로그램처럼 바탕화면에 아이콘 보관함을 두고, 탭으로 나눠 쓰고, 어디든 옮길 수 있게. 필요하면 메모도.

- 유형: windows (PC 전용)
- 시작일: 2026-10-16
- 상태: 🌱 기획

## 1. 무엇을, 왜

- 해결하려는 문제: 바탕화면 아이콘이 어지럽고, 원하는 프로그램을 찾기 느리다.
- 누가 쓰나: 나
- 이렇게 되면 성공:
  - 바탕화면에 보관함 몇 개를 두고, 탭(예: 작업 / 게임 / 폴더)을 눌러 바꿔 가며 바로 실행
  - 보관함을 끌어서 아무 데나 옮기고, 크기를 바꾸고, 재부팅해도 그대로

## 2. 핵심 기능

### 1단계 — 보관함 하나 제대로
- [ ] (로직) 보관함 데이터: 이름, 위치, 크기, 탭 목록, 탭별 아이템(바로가기 경로·순서) + 저장/불러오기
- [ ] (로직) 바로가기(.lnk)·파일·폴더 정보 읽기: 표시 이름, 실제 대상
- [ ] 바탕화면에 붙는 보관함 창: 다른 창 뒤에 있고, 작업 표시줄에 안 보이고, Win+D 를 눌러도 남음 *(난이도 높음 — `/research` 먼저)*
- [ ] 아이콘 + 이름 표시, 더블클릭으로 실행
- [ ] 파일·바로가기를 끌어다 놓아 추가, 보관함 안에서 끌어서 순서 변경, 삭제

### 2단계 — 탭과 자유 배치
- [ ] 보관함 안의 탭: 탭 추가·이름 바꾸기·삭제, 클릭으로 전환
- [ ] 보관함 끌어서 이동, 모서리로 크기 조절, (로직) 격자·화면 가장자리에 착 붙기
- [ ] 보관함 여러 개: 추가·삭제·이름 바꾸기, 접기/펼치기
- [ ] 윈도우 켤 때 자동 실행

### 3단계 — 메모
- [ ] 메모 탭: 탭 종류를 "메모"로 하면 글을 쓸 수 있는 칸 (자동 저장)

## 3. 나중에 (MVP 이후)

- 보관함 색·투명도 테마
- 바탕화면 아이콘 자동 분류 (확장자별)
- 단축키로 보관함 전체 숨기기/보이기

## 4. 하지 않을 것

- 바탕화면 배경화면 바꾸기, 위젯(날씨·시계 등)

## 5. 기술 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 언어/화면 | C# + WPF (.NET 10) | 투명 창·끌어다 놓기·Windows 연동이 쉬움 |
| 바탕화면에 붙이기 | 후보: Windows 바탕화면 창(WorkerW/Progman) 아래에 붙이는 방식 | `/research` 에서 오픈소스 구현 확인 |
| 저장 | JSON 파일 (`%AppData%\simple-desk`) | |
