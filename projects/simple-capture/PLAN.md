# simple-capture 기획서 — 보다 간단한 캡처

> 캡처·녹화·GIF·텍스트 추출을 한 창에서. 범위를 잡기 쉽고, 저장 위치와 파일 이름은 신경 쓰지 않게.

- 유형: windows (PC 전용)
- 시작일: 2026-10-16
- 상태: 🌱 기획

## 1. 무엇을, 왜

- 레퍼런스: **픽픽(PicPick)** — 지금 쓰는 캡처 프로그램. 익숙한 기능·화면은 살리고 불편한 점을 고친다.
- 해결하려는 문제: 기존 캡처 프로그램은 범위를 맞추기 불편하고(창 끝을 정확히 잡아 끌어야 함), 저장 위치·파일 이름을 매번 정해야 한다.
- 누가 쓰나: 나 — 레퍼런스 이미지를 많이 모으는 작업
- 이렇게 되면 성공:
  - 범위 창을 한 번 맞춰 두고 버튼만 눌러 **연속 캡처**할 수 있다
  - 버튼 하나로 **정해 둔 폴더에, 정해 둔 이름 + 번호**로 저장된다
  - 캡처한 화면의 글자를 바로 복사할 수 있다

## 2. 핵심 기능

> 한 항목 = `/feature` 한 번. 위에서부터 순서대로. **(로직)** 항목은 화면 없이 테스트로 완성하는 부분.

### 1단계 — 캡처하고 저장하기
- [ ] (로직) 빠른 이름 짓기: "동영상 레퍼런스" 입력 → `동영상 레퍼런스 1.png`, `동영상 레퍼런스 2.png` … 폴더에 이미 있는 번호 다음부터, 파일 이름에 못 쓰는 문자 처리
- [ ] (로직) 설정 저장/불러오기: 저장 경로 3개, 테두리 색·투명도, 크기 프리셋 (`%AppData%\simple-capture\settings.json`)
- [ ] (로직) 비율·크기 프리셋 계산: 기본 비율(16:9, 4:3, 1:1, 9:16 …) + 내가 저장한 px 크기, 화면 밖으로 나가지 않게 맞춤
- [ ] 메인 도구창: 캡처 버튼 3개(경로 1·2·3) + 클립보드 버튼 + 빠른 이름 입력칸
- [ ] 전체 화면 캡처 → 파일 저장 / 클립보드
- [ ] 창 캡처 (브라우저 창 등 선택한 창)
- [ ] 부분 캡처 (드래그로 영역을 그려서 한 번 캡처)

### 2단계 — 범위 캡처 창 (이 프로그램의 핵심)
- [ ] 범위 캡처 창: 항상 맨 앞, 속이 비치는 테두리 창, 테두리 투명도 조절
- [ ] (로직) 손잡이 8개 계산: 네 변 가운데 4개 + 꼭짓점 4개, 끌었을 때 새 영역 계산 (최소 크기·비율 고정 지원)
- [ ] 손잡이 8개 UI: 창 끝을 정확히 잡지 않아도 큼직한 손잡이로 크기 조절
- [ ] 범위 창 고정(잠금) + 버튼/단축키로 연속 캡처
- [ ] 범위 창에서 비율·크기 프리셋 선택, 현재 크기를 프리셋으로 저장
- [ ] 전역 단축키 (프로그램이 뒤에 있어도 캡처)

### 3단계 — 텍스트 추출
- [ ] 캡처한 영역의 글자 인식(OCR, 한국어·영어) → 클립보드로 복사

### 4단계 — 녹화와 GIF
- [ ] 화면 녹화 (MP4): 전체 / 창 / 부분 / 범위 창 — 캡처와 같은 방식으로 영역 지정
- [ ] (로직) GIF 품질 프리셋: 저화질(작은 용량) / 고화질 — 초당 프레임, 크기, 색 수
- [ ] 녹화 → GIF 바로 변환
- [ ] 간단 편집: 앞뒤 자르기, 크기 줄이기

## 3. 나중에 (MVP 이후)

## 5. 기술 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 언어/화면 | C# + WPF (.NET 10) | Windows 전용 기능(항상 위, 투명 창, 전역 단축키, 클립보드)이 가장 쉽고 가벼움 |
| 화면 캡처 | 처음엔 GDI(BitBlt) → 필요하면 Windows.Graphics.Capture | 단순한 것부터 |
| 텍스트 추출 | Windows 내장 OCR (`Windows.Media.Ocr`) | 추가 설치 없음. 한국어 언어 팩 필요 |
| 녹화 / GIF | 후보: ScreenRecorderLib, ffmpeg | `/research` 에서 라이선스·용량 확인 후 결정 |
| 설정 저장 | JSON 파일 | 사람이 읽고 고칠 수 있음 |
