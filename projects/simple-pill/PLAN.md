# simple-pill 기획서 — 보다 간단한 약 타이머

> 약 먹을 시간을 알려주고, **지금 술 마셔도 되는지**를 한눈에 보여주는 휴대폰 앱.

- 유형: mobile (Android 우선)
- 시작일: 2026-10-16
- 상태: 🌱 기획

## 1. 무엇을, 왜

- 해결하려는 문제: 약을 언제 먹었는지 잊어버리고, 먹은 약 때문에 술을 언제까지 피해야 하는지 모른다 (특히 타이레놀).
- 누가 쓰나: 나
- 이렇게 되면 성공:
  - 앱을 열면 첫 화면에 **"술 피하기: 3시간 20분 남음"** 같은 큰 표시
  - "방금 먹었어요" 한 번 누르면 기록·알림·계산이 다 된다

> ⚠️ **의학 정보 원칙** (가장 중요)
> - 앱의 모든 수치(복용 간격, 하루 최대량, 술 피하기 시간)는 **출처를 데이터에 함께 저장**한다 — 식약처 의약품 허가정보, 제품 설명서, 약학정보원 등.
> - 출처를 찾지 못한 수치는 넣지 않는다. AI 가 지어낸 숫자 금지.
> - 화면에 항상 "참고용입니다. 정확한 복용법은 약사·의사와 상담하세요." 문구.
> - **술 피하기 시간 계산 기준 (2026-10-16 결정)**: 약이 몸에서 빠지는 시간(반감기)으로 계산한다.
>   - `술 피하기 끝 = 마지막 복용 시각 + max(반감기 × 배수, 최소 대기 시간)`
>   - 반감기는 약마다 **출처와 함께** 데이터에 저장. 배수(기본 5배 — 약이 대부분 빠지는 기준)도 화면에 근거로 표시.
>   - **최소 대기 시간 기본값 24시간** — 사용자 기준 "보통 24시간 이상". 설정에서 바꿀 수 있음.
>   - 화면에는 계산식과 출처를 함께 보여준다 ("반감기 약 ○시간 × 5 = ○시간, 최소 24시간 적용").

## 2. 핵심 기능

- [ ] (로직) 약 정보 데이터 형식: 이름, 성분, 복용 간격, 하루 최대 횟수, 술 주의 규칙, **출처** (출처 없으면 저장 거부)
- [ ] (로직) 복용 기록으로 "술 피하기 끝나는 시각" 계산 — 반감기 × 배수와 최소 대기 시간(기본 24시간) 중 큰 값, 여러 약이면 가장 늦은 시각
- [ ] (로직) 다음 복용 가능 시각 계산 — 최소 간격, 하루 최대 횟수 넘으면 경고
- [ ] 첫 화면: 술 상태 큰 표시(🟢 괜찮음 / 🔴 피하세요 + 남은 시간) + 오늘 먹은 약
- [ ] "방금 먹었어요" 버튼 + 약 고르기, 기록 지우기
- [ ] 내 약 등록/수정 화면 (출처 입력 칸 포함)
- [ ] 휴대폰에 저장 (앱을 껐다 켜도 유지)
- [ ] 복용 알림: 정해진 시각 / "다음 복용 가능" 시각에 알림
- [ ] 안내 화면: 면책 문구 + 각 수치의 출처 목록

## 3. 나중에 (MVP 이후)

- 홈 화면 위젯 (앱 안 열고 술 상태 보기)
- 식약처 공공데이터로 약 검색해서 자동 등록
- 복용 통계

## 4. 하지 않을 것

- 진단·처방처럼 보이는 기능 ("이 약을 드세요" 추천)
- 회원가입·서버 — 데이터는 휴대폰에만

## 5. 기술 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 앱 | Expo (React Native) | **Android** 우선 (나중에 iPhone 도 가능). **Expo Go** 앱으로 빌드 없이 바로 실행, 완성되면 APK 로 설치 |
| 로직 | `src/logic/*.mjs` + `node --test` | 화면 없이 계산을 정확히 테스트 |
| 알림 | 후보: expo-notifications (로컬 알림) | 서버 필요 없음 |
| 저장 | 후보: expo-sqlite 또는 AsyncStorage | 기능 구현 때 결정 |
