# simple-pdf 기획서 — 보다 간단한 PDF

> 알PDF 처럼 보기 좋은 화면, 하지만 광고 없고 가볍고 쓰기 편하게. 피그마처럼 전체 페이지를 한눈에 보고 다루기.

- 유형: windows (PC 전용)
- 시작일: 2026-10-16
- 상태: 🌱 기획

## 1. 무엇을, 왜

- 해결하려는 문제: 알PDF 는 화면(UI)은 좋지만 광고가 있고, 이상한 버그가 있고, 무겁고, 편집 기능이 쓰기 불편하다(UX).
- 누가 쓰나: 나 — 매일 PDF 를 열어 보고 가끔 페이지 정리·간단 편집
- 이렇게 되면 성공:
  - 켜는 데 1초 안쪽, 100쪽 문서도 스크롤이 끊기지 않는다
  - 전체 페이지를 한 화면에 펼쳐 놓고 끌어서 순서 바꾸기·삭제·합치기
  - 글상자·도형·형광펜을 고민 없이 바로 넣는다

> **원칙**: 알PDF 의 *기능 목록과 화면 배치를 참고해* 직접 만든다. 알PDF 의 프로그램 파일을 뜯거나 코드·아이콘·이미지를 가져오지 않는다 (상용 프로그램 — 약관·저작권 문제).

## 2. 핵심 기능

### 1단계 — 가볍고 빠른 보기
- [ ] (로직) PDF 열기: 페이지 수·페이지 크기 읽기, 잘못된 파일이면 친절한 오류
- [ ] 페이지 그리기 + 세로 스크롤 보기 (보이는 페이지만 그려서 가볍게)
- [ ] (로직) 확대/축소 계산: 폭 맞춤, 쪽 맞춤, 배율(%), Ctrl+휠
- [ ] 페이지 이동: 번호 입력, 왼쪽 썸네일 목록
- [ ] 글자 검색 (다음/이전, 결과 강조)
- [ ] 탭으로 여러 문서 열기, 최근 파일, 끌어다 놓아 열기
- [ ] 윈도우 기본 PDF 프로그램으로 등록 (더블클릭하면 이걸로 열림)

### 2단계 — 피그마식 전체 페이지 팔레트
- [ ] 전체 페이지 보기: 모든 페이지를 격자로 펼친 캔버스, 휠로 확대, 스페이스+드래그로 이동
- [ ] (로직) 페이지 편집 명령: 순서 바꾸기·삭제·회전·복제 + 실행 취소/다시 실행
- [ ] 팔레트에서 끌어서 순서 바꾸기, 여러 장 선택해 삭제·회전
- [ ] 다른 PDF 를 끌어다 넣어 합치기, 선택한 페이지만 새 PDF 로 저장

### 3단계 — 가벼운 편집 (피그마처럼 쉽게)
- [ ] 도구 막대: 선택 / 글상자 / 사각형·원·화살표 / 형광펜 / 메모 — 단축키 한 글자(V, T, R, H …)
- [ ] 넣은 요소를 끌어서 옮기기·크기 바꾸기·삭제
- [ ] 저장 (덮어쓰기 / 다른 이름으로), 저장 안 하고 닫으면 묻기

## 3. 나중에 (MVP 이후)

- 양식(폼) 채우기, 서명 넣기
- PDF ↔ 이미지 변환, 인쇄 미리보기 개선
- 다크 모드

## 4. 하지 않을 것

- 광고, 로그인, 클라우드 기능
- PDF 원본 글자 직접 수정 (워드처럼 고치기) — 매우 어렵고 무거워짐

## 5. 기술 결정

| 항목 | 선택 | 이유 |
|---|---|---|
| 언어/화면 | C# + WPF (.NET 10) | 가볍고 Windows 에 잘 맞음 |
| PDF 그리기 | 후보: PDFium 기반 라이브러리 (크롬이 쓰는 PDF 엔진) | 빠르고 정확. `/research` 에서 감싸는 라이브러리·라이선스 결정 |
| 페이지 편집·저장 | 후보: PDFsharp | `/research` 에서 확인 |

## 6. 열린 질문

- 알PDF 에서 **불편했던 점·버그**를 구체적으로 알려주면 기능 목록에 반영 (예: "썸네일 끌기가 자꾸 튄다")
- 가장 자주 쓰는 기능 3가지는?
- 알PDF 화면에서 꼭 닮았으면 하는 부분은? (스크린샷이 있으면 가장 좋음)
